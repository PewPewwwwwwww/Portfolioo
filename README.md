# Erick Gozo — Portfolio

Personal portfolio website of **Erick Gozo**, a full-stack web developer working with React, Node.js, Express, MongoDB, and PostgreSQL.

## Featured Projects

- **CM-HelpHub**: Community support ticketing platform with role-based access control and moderator workflows.
- **Ultimate Frisbee Management System**: Tournament management platform with automated brackets, team rosters, and live scoring.

## Built With

- HTML5
- CSS3
- Vanilla JavaScript

## Running Locally

No build step required. Clone the repository and open `index.html` in a browser:

```bash
git clone https://github.com/PewPewwwwwwww/Portfolioo.git
cd Portfolioo
```

## Project Structure

```
├── index.html        # Page markup and content
├── Erick_Styles.css  # Styles
├── Erick_Main.js     # Typewriter effect, project modals, contact actions
└── img/              # Images and icons
```
